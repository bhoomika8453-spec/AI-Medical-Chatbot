🏥 AI Medical End-to-End Chatbot

📌 About the Project

The AI Medical End-to-End Chatbot is a healthcare management platform developed to make healthcare services more accessible and efficient. It provides AI-assisted healthcare guidance, patient management, doctor management, appointment booking, medical history tracking, disease prediction, insurance management and emergency support.

🎯 Objectives

- To improve healthcare accessibility.
- To provide AI-assisted medical guidance.
- To simplify appointment booking.
- To maintain digital patient medical records.
- To support symptom-based disease prediction.
- To improve communication between patients and doctors.

✨ Features

1. AI Medical Chatbot – Healthcare-related assistance.
2. Disease Prediction – Symptom-based disease prediction.
3. Patient Management – Patient registration and profiles.
4. Doctor Management – Doctor dashboard and patient records.
5. Appointment Booking – Online appointment management.
6. Medical History – Digital medical record management.
7. Emergency Support – Emergency healthcare assistance.
8. Insurance Management – Insurance claim submission and management.

⚙️ Installation and Setup

Step 1: Clone the repository

git clone https://github.com/bhoomika8453-spec/AI-Medical-Chatbot.git

Step 2: Open the project folder

cd AI-Medical-Chatbot

Step 3: Install dependencies

pip install -r requirements.txt

Step 4: Run the application

python app.py

Step 5: Open in browser

http://127.0.0.1:5000
